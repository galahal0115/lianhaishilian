# 恋还是练

一款俯视角像素动作生存游戏，由哈克水水菌提出创意、设计需求并持续试玩反馈，使用 OpenAI AI 辅助完成程序开发与部分美术制作。

## 游戏内容

- **五关试炼**：各类小怪从第一关逐步登场，后续关卡增加数量、血量与伤害，第五关迎战奶熊。
- **关末强化**：前四关结束，各选一次攻速、攻击或最大生命 +20%。
- **奶熊挑战**：角色按 20 级成长，再提升 50% 攻击、攻速和生命，直接挑战 Boss。
- **无限世界**：持续刷新小怪与 Boss。
- 连招、二段跳、闪避、空中下坠攻击、蓄力次元斩与飞剑技能；苹果树回血、经验升级及通关宝箱。

## 下载与安装

在本仓库的 [Releases 下载页面](https://github.com/galahal0115/lianhaishilian/releases/tag/v1.0.0) 下载 `LianHaiShiLian-Setup-1.0.0.exe`。安装后使用桌面快捷方式启动，无需安装 Node.js 或浏览器。

当前构建目标是 **Windows 10/11 x64**；已在开发电脑完成安装与启动验证，尚未覆盖不同硬件的兼容性测试。安装包未进行数字签名，Windows 可能提示未知发布者。暂未提供 macOS、Linux 或手机版。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD | 移动、改变攻击及飞剑方向 |
| 鼠标左键 | 普攻连招；空中下坠攻击 |
| 鼠标右键 | 闪避，冷却约 1 秒，期间免伤 |
| 空格 | 跳跃、空中二段跳 |
| Q | 起飞释放飞剑，40 能量、18 秒冷却 |
| 按住 E / 松开 E | 蓄力 / 释放次元斩 |
| F | 靠近通关宝箱时打开 |
| Esc | 暂停、设置、返回菜单 |
| F11 | 桌面版全屏切换 |

## 本地开发与打包

游戏使用 HTML Canvas、原生 JavaScript 和 Electron。安装 Node.js 22 或更新版本及 npm，在项目根目录运行：

```sh
npm ci
node node_modules/electron/install.js
npm test
npm start
```

第二条命令用于确保 Electron 运行环境已下载（部分 npm 配置会阻止依赖安装脚本）。首次安装依赖和打包组件需要网络。

在 Windows 上生成安装包：

```sh
npm run dist
```

输出为 `release/LianHaiShiLian-Setup-1.0.0.exe`。`desktop/stage.cjs` 将运行文件整理到 `build/app`；安装包包含实际使用的图片、音乐、音效、视频和字体。

## 目录

- 根目录 HTML / CSS / JS：游戏逻辑、绘制、界面与声音。
- `assets/`：当前运行必需的素材及字体许可。
- `desktop/`：桌面窗口、素材整理与启动检查。
- `checks/`：数值、技能、受击和声音生命周期检查。
- `package.json` / `package-lock.json`：依赖与打包配置。

## 验证与限制

自动检查覆盖奖励选择、逐关强度、奶熊属性、Q 技能及声音停止规则。桌面程序支持 `--smoke-test` 静音检查启动、素材加载、奖励界面和技能。测试通过不代表已完成长时间通关平衡或所有电脑的兼容性验证。

当前主菜单与普通关卡音乐来源文件相同，因此听起来相同；后续可以替换。数值与美术仍在迭代。
